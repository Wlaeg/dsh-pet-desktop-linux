[`awesome-dsh-plugin/awesome-dsh-plugin`](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin).

list's READMEs are generated from these YAML files.

repository's latest GitHub Release, so storefronts can offer a prebuilt install
that skips the source build.
